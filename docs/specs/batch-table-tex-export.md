# バッチ実験結果の論文用TeX出力 仕様変更設計書

## 背景
- バッチ実験（結果タブ/統計検定タブ）のテーブルを論文のTeX原稿に直接貼り付けたいという要望がある。
- 評価指標や統計検定項目が今後増える予定のため、列選択やテーブル増設に耐えられるUI/構造にしておく必要がある。
- 将来的に分布図・分布統計などの可視化/エクスポート機能も追加する予定。

## 対象
- 結果タブ: Layer1/Layer4 評価指標テーブル（現行2表、将来3表想定）
- 統計検定タブ: 検定結果テーブル（現行1表、将来3表想定）

## 要件
- R1: 各テーブルを論文TeX形式でコピーできるようにする（booktabs想定）。
- R2: エクスポート対象に含める列をユーザーがチェックボックスで選択できること。
- R3: 追加の評価指標/検定指標が増えても列定義を追加するだけでエクスポートに反映できる構造にする。
- R4: 将来追加する分布図/分布統計などの機能を配置するコンテナを用意する。
- R5: 既存のテーブル表示（結果/統計）自体は壊さず、エクスポートUIを付与する形にする。

## UI/UX設計
- 各テーブルの直下に「論文用TeX出力」カードを配置する。
  - 含める列のチェックボックス（デフォルト全選択）。
  - 生成されたTeXコードのプレビュー（読み取り専用テキストエリア）。
  - "TeXをコピー" ボタンでクリップボードコピー。完了トースト/メッセージを簡易表示。
- タブ全体のサイドに「研究用アクションコンテナ」を用意し、分布図等の今後のボタン置き場を確保する。

## データ設計
- 共通の列定義型を用意する。
  - `key`, `label`, `align (l/c/r)`, `formatter(row) => string`。
  - 選択状態は key ベースで管理。将来列追加時は定義配列に項目を追加するだけでよい。
- Layer1/Layer4 テーブル: `ModelStatistics` を1行として使用。割合は`xx.x%`、コスト/レイテンシは千位区切りを踏襲。
- 統計検定テーブル: 現在選択中の指標に対する `StatisticalTestResult[]` を1行として使用。p値、効果量は既存フォーマットを利用。

## TeX出力仕様
- `\begin{table}[htbp]` + `\centering` + `\begin{tabular}{...}` を採用。
- 罫線は `booktabs`（`\toprule`, `\midrule`, `\bottomrule`）。
- 列位置は列定義の `align` を使用（Model列は `l`、数値列は `r`、フラグ列は `c`）。
- テーブルキャプション/ラベルを受け取り、空の場合はデフォルトでタイトルを用いる。
- Model名などに含まれる `_` などは簡易エスケープしてTeXが壊れないようにする。

## 配置計画
- `BatchResults.tsx` の Layer1/Layer4 セクションの下部にエクスポートカードを追加。
- `StatisticsTab.tsx` の各検定テーブルの下部にエクスポートカードを追加（現在は選択中指標のみをエクスポート）。
- 右（または下部）に「研究ユーティリティ」カードを新設し、分布図など将来のボタンを追加できる余白を確保。

## 実装方針
- 共通コンポーネント `LatexTableExporter`（仮名）を `src/pages/research-experiment/components/` に追加し、列定義と行データを渡すだけで動作させる。
- 現行データ表示ロジックは維持しつつ、エクスポート用の定義を各セクションに配置。
- 依存ライブラリ追加なし（React標準＋既存スタイルのみ）。

## テスト観点
- 各テーブルで列のオン/オフが即時TeX出力に反映されること。
- コピー操作でクリップボードに期待するTeX文字列が入ること（開発環境で手動確認）。
- 既存テーブル表示が崩れていないこと（UI確認）。
- 将来列追加時に列定義配列へ要素を足すだけでエクスポートが増えることをコードレビューで確認。
